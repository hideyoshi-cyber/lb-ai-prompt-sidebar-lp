探す・評価する・並べる：★評価と検索、使わないものを隠す

探す・整理 2026年10月15日 読む時間：約4分

目的別のコマンドは、タブごとに並んでいます。数が多くても、迷わず使い続けるために、検索・★評価・並び替え・隠すの4つの機能を使いこなしましょう。

CONTENTS
  1. 検索
  2. ★評価
  3. 並び替え
  4. 使わないものを隠す
  5. AIニュースと「AIを使いこなすセオリー」

検索

上の検索欄に、キーワードを入れると、タブをまたいで探せます。タイトル・解説・カメラワーク・英語のプロンプトも、対象です。

  • / または Ctrl + K：検索欄へ移動（収納中なら開きます）
  • Esc：検索をクリア、またはダイアログを閉じる
  • ?：ヘルプを開く

隠したタブのコマンドも、検索では見つかります。

★評価

行の ★ を押すと、5段階で評価できます。点灯している一番右の★を、もう一度押すと解除です。未評価の行は、マウスを乗せたときだけ★が出ます。

評価したコマンドは、「★ 評価したプロンプト」のフォルダに集まります。評価は、あなたのPCに保存されます。

並び替え

一覧の上の「⇅」で、並び順を選べます。

  • 標準（シートの順）
  • ★の多い順／★の少ない順
  • 名前順
  • 更新が新しい順／作成が新しい順

よく使うものを、いちばん上に出したいときは、「★の多い順」がおすすめです。

使わないものを隠す

使わないタブ・フォルダ・AIランチャーのアイコンは、右クリックして「〇〇を隠す」で、隠せます。隠しても、中身は消えません。いつでも、元に戻せます。

隠すもの場所戻し方
タブ一番上のタブの並び並びの右端の「👁」→ チェックを付ける
フォルダタブの中で「すべて見る」を押すと出る【トラブル】【勉強】などの並び同上（タブごとに設定できます）
AIランチャー上のAIのアイコン右端の「👁」を押して、押すだけで切り替え

「👁」に数字が付いているときは、隠しているものがある印です。「すべて表示する」もあります。

AIニュースと「AIを使いこなすセオリー」

ヘッダーの 📰 で、AIのニュースを読めます（赤丸は未読数）。記事を押すと、新しいタブで開き、既読になります。「⚙ フィード」で、フィードのオン・オフや追加ができます。▦ と ☰ で、画像つきのカードと一覧を切り替えられます。

「AIを使いこなすセオリー」は、生成AIを使うときの進め方を、8つの順番にまとめたものです。どちらも、無料版で使えます。

選んで、整えて、いつものAIへ。
